# Adaptive AI Tutor 🎓

## 📌 Project Overview

Adaptive AI Tutor is a web-based learning platform designed to provide students with a personalized learning experience. It aims to make learning more effective by adapting to students' learning needs and progress.

## 🚀 Features

- User-friendly web interface.
- Student-focused learning platform.
- Personalized learning experience.
- Python-based backend.
- HTML templates and static resources.
- Database support for storing application data.

## 🛠️ Technologies Used

- **Python** – Backend development
- **Flask** – Web framework
- **HTML, CSS, JavaScript** – Frontend development
- **Mysql** – Database

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd adaptive_ai_tutor
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000/
```
